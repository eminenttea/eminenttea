# Eminent Tea Catalogue Flipbook

This folder is ready for GitHub Pages and contains a fully self-hosted 64-page catalogue reader.

## Upload

Upload **all files and the `pages` folder** from this package to the root of your GitHub repository.

Then open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.

The included `CNAME` file connects the site to `eminent.lk`. After GitHub reports a successful DNS check, enable **Enforce HTTPS**.

Do not rename the files in the `pages` folder.
